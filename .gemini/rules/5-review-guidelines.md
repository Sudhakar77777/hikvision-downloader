# Review Guidelines

- **Surgical Edits Only:** Touch only the lines required to satisfy the task. Do not reformat adjacent functions, reorder unrelated imports, or rewrite functional modules.
- **Git Safety:** Never execute `git` write commands (`add`, `commit`, `push`, `reset`, `rebase`, `checkout`). Git operations remain exclusively under human control.
- **Diff Accountability:** Every proposed change must be clear and explainable during user reviews.
